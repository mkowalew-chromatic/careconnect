New React Native component library on the same design tokens as `@careconnect/design-system` (a unit test fails if they drift): Text, Button, Badge, Card, TextField, ChipGroup, OptionCard, ListRow, StatCard, Avatar, Alert, EmptyState, Spinner, LoadingState, StepProgress, SlotPicker, MessageBubble and Screen. `MotionProvider` / `useMotion` let animated components render a fixed frame for visual tests and for users with Reduce Motion on.
